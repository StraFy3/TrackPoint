# TrackPoint

Универсальный трекер личных событий и активностей.

## О проекте

TrackPoint — это веб-приложение, в котором пользователь ведёт приватный
дневник событий и активностей: книги, фильмы, спорт, поездки, учёбу и
всё остальное, что можно отнести к категории. Каждая запись содержит
описание, комментарий, оценку, дату и статус.

Записи пользователя видны только ему. Публично на главной странице
отображается агрегированная статистика по категориям среди всех
пользователей: название категории, количество записей и средняя оценка.

## Функциональные требования

### Роль «Гость»
- Просмотр главной страницы с топом популярных категорий
  (название, количество записей, средняя оценка).
- Регистрация нового аккаунта.
- Вход в существующий аккаунт.
- Просмотр страницы «О проекте».

### Роль «Пользователь»
- Регистрация и вход по email и паролю.
- Личный кабинет (приватный профиль, доступен только владельцу).
- Создание записи со следующими полями:
  - название;
  - категория (выбор из списка, добавленного админом);
  - описание;
  - комментарий / ощущения;
  - оценка (1–5 звёзд);
  - дата события;
  - статус (запланировано / в процессе / завершено);
  - ссылка на офиц. источник (+подсказки)
  - теги.
- Просмотр списка своих записей.
- Редактирование своей записи.
- Удаление своей записи.
- Фильтрация записей по категории, статусу и дате.
- Поиск по названию и описанию.
- Личная статистика: количество записей по категориям,
  средняя оценка.
- Выход из аккаунта.

### Роль «Админ»
- Управление категориями: создание, редактирование,
  удаление.
- Управление пользователями: просмотр списка, блокировка.
- Просмотр агрегированной статистики
  (топ категорий, общее количество записей, средние оценки).
- Не имеет доступа к содержимому записей пользователей.

### Системные требования
- Хранение сессии через cookies.
- Хэширование паролей.
- Валидация форм на клиенте и сервере.
- Адаптивная вёрстка для мобильных устройств и десктопа.
- Приватность: чужие профили и записи недоступны другим пользователям.
